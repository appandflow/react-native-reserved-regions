# react-native-reserved-regions 0.1.0

The first stable release of provider-relative display divisions and occlusions
for React Native's New Architecture.

## API

- `ReservedRegionsProvider` measures the native view it renders and shares
  regions with descendants in that view's coordinate space.
- `useReservedRegions()` returns an array of divisions and occlusions. Divisions
  include `occludesContent`; zero-width and zero-height divisions are preserved.
- `useReservedRegionsReady()` distinguishes a pending measurement from a measured
  empty result. `ReservedRegionsGate` optionally delays children until ready.
- iOS queries UIKit reserved regions and refreshes on layout and hinge updates.
  Android observes Jetpack WindowManager folding features and display cutouts.

## Migration

There are no API or native implementation changes from `0.1.0-alpha.3`. Install
`react-native-reserved-regions` without a prerelease version to receive `0.1.0`
through npm's `latest` tag. Reinstall pods and rebuild when upgrading from an
older alpha to pick up its native fixes.

React Native's New Architecture is required. The tested example uses
`0.88.0-rc.1`; a broader supported version range has not been established.
iOS functionality requires the iOS 27.1 SDK and runtime. Older SDKs compile out
observation and older runtimes report empty regions. Android requires API 24+,
API 28+ for cutouts, and device support for Jetpack WindowManager folding features.

## Verification and limits

- Android initial measurement and provider-relative cutout geometry are recorded
  in the [Android verification report](../verification/one-shot-mount-listener-android-2026-09-21.md).
- Dynamic Duo fold updates, including division removal at 180° and restoration
  at 113° with unchanged provider bounds, are recorded in the
  [dynamic iOS verification report](../verification/dynamic-fold-ios-2026-09-22.md).
- iOS SDK compilation and initial measurement are recorded in the
  [iOS verification report](../verification/hinge-interaction-requery-ios-2026-09-21.md).
- Package contents, declarations, unit tests, formatting, lint, and documentation
  builds are release gates. The tag's CI also builds the iOS and Android examples.

Readiness means measurement completion, not hardware support or guaranteed
first-frame delivery. The example's React Native event-beat patch is not applied
to consuming apps. Readiness-gated Reanimated content on the tested Android stack
needs the documented Worklets workaround; keeping the animated subtree mounted
avoided that failure. See the platform and performance guides before using the
gate with animated content.

Physical-device and multiple-window behavior remain unverified. The iOS 27.1
APIs were tested with a beta SDK and simulator runtime.
