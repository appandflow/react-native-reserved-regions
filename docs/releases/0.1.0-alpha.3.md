# react-native-reserved-regions 0.1.0-alpha.3

View-relative reserved regions with optional readiness gating.

## New and fixes

- `ReservedRegionsGate` optionally delays children until the enclosing provider
  has completed its first measurement. An empty measured result still opens it.
- iOS providers re-query geometry on UIKit hinge updates.
- Android uses a one-shot initial Fabric mount listener, avoiding measurements
  after unrelated app-wide mount batches.
- The website adds a performance guide and an interactive rotation illustration
  with upright, provider-relative coordinate labels.

## Migration

The existing provider and hook APIs are unchanged. The gate is optional; keep
it inside a sized `ReservedRegionsProvider`. Install pods and rebuild the native
app to pick up the native observation fixes.

React Native's New Architecture is required. The tested example uses
0.88.0-rc.1. iOS reserved regions require the iOS 27.1 SDK and runtime; older
SDKs compile out observation. Android requires API 24+, with API 28+ for cutouts
and a compatible WindowManager implementation for folding features.

## Verification and limits

- Android mount-listener behavior and initial measurement are recorded in the
  [Android verification report](../verification/one-shot-mount-listener-android-2026-09-21.md).
- iOS 27.1 builds and initial hinge-triggered re-query are recorded in the
  [iOS verification report](../verification/hinge-interaction-requery-ios-2026-09-21.md).
  That report does not establish dynamic posture-change delivery.
- Unit coverage includes gate readiness and measured-empty behavior.
- Package, native compilation, formatting, lint, types, tests, and documentation
  builds are release gates. See the release tag's CI for exact-candidate results.

Readiness is measurement completion, not hardware support or guaranteed
first-frame delivery. The existing iOS synchronous-event and Worklets FIFO
patch limitations still apply; consult the platform and performance guides.
Installing this package does not apply those patches to consuming apps.
Physical-device and multiple-window behavior remain unverified.

This remains an alpha release even when installed through `latest`.
