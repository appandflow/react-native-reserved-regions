# react-native-reserved-regions

Provider-scoped reserved display regions for React Native

## Installation


```sh
npm install react-native-reserved-regions
```


## Usage


```js
import { ReservedRegionsView } from "react-native-reserved-regions";

// ...

<ReservedRegionsView color="tomato" />
```
